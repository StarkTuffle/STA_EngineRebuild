# StarkTruffle Additions - Engine Rebuild

> An engine rebuild mod for Project Zomboid

---

## Overview

This mods allows you to improve the engine quality of PZ vehicles, improving horsepower and reducing failed engine starts. In Vanilla this value is set at vehicle generation and cannot be changed. Sandbox settings allow full customization of your expirience with the system.

---

## Features

- Max out the quality of any vehicle engine
- Fully customizable in sandbox settings, set the levels required, parts needed, and neccessary condition
